# The initials' faces

The capitals A to Z of five faces, as SVG path data, taken unchanged from
[initialis](https://github.com/azlen/initialis) (`render/fonts/caps/`), which took them from
the font files. Each face is under the SIL Open Font License 1.1 (`OFL.txt`).

| File | Face | By |
|---|---|---|
| `unifrakturmaguntia-400.json` | UnifrakturMaguntia | j. 'mach' wust |
| `uncial-antiqua-400.json` | Uncial Antiqua | Astigmatic (AOETI) |
| `macondo-swash-caps-400.json` | Macondo Swash Caps | John Vargas Beltrán |
| `cinzel-decorative-700.json` | Cinzel Decorative Bold | Natanael Gama, The Cinzel Project Authors |
| `eb-garamond-700.json` | EB Garamond Bold | Georg Duffner, Octavio Pardo, The EB Garamond Project Authors |
